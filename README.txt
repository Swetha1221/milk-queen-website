MILK QUEEN WEBSITE - SETUP

This ZIP already contains all three code files and the assets folder.

Folder structure:
Milk_Queen_Website_Complete/
  index.html
  style.css
  script.js
  assets/
    logo.jpeg
    sweets-bg.jpg

HOW TO OPEN:
1. Extract the ZIP file (do not open files inside the ZIP preview).
2. In VS Code choose File > Open Folder.
3. Select the extracted Milk_Queen_Website_Complete folder.
4. Open index.html.
5. Right-click inside index.html > Open with Live Server.

ASSETS:
- logo.jpeg is the Milk Queen logo used in the header and footer.
- sweets-bg.jpg is the sweets background used behind the launch message.
- Both are already placed in the assets folder. Do not move them.
- If you replace either image, keep the exact same filename and put it inside assets.
- The product cards currently use decorative sweet symbols. To add real product-pack photos later, put the photos in assets and update the product card image paths in index.html.

All files must stay together in the same project folder.
